# Licensing

masaudit uses three licenses, so companies can adopt it without legal friction.

| What | License | Files |
|---|---|---|
| The scanner's code | [Apache-2.0](LICENSE) | `src/`, `scripts/`, `tests/`, workflows |
| Fix snippets (`fix_code` in the rules, `fixes-*.md` in the skill) | [MIT-0](LICENSES/MIT-0.txt) | paste them into any app, no attribution needed |
| Explanations adapted from the book and from OWASP MASVS/MASWE | [CC BY-SA 4.0](LICENSES/CC-BY-SA-4.0.txt) | rule `why`/`fix` text, skill references |

**In plain words:** running masaudit, and keeping or sharing the reports it writes, puts no obligation on you.
ShareAlike applies only if you redistribute a modified copy of the explanatory text itself.

masaudit is not an OWASP project. OWASP doesn't certify apps and doesn't endorse this tool.
